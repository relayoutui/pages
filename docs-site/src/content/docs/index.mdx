Relayout is a lightweight framework which separates layout from aspect and handles structure, spacing and
boundaries, not colors, typography or styling. It works as CSS classes, as web components, or both, in any
project, design system or framework.

There are four layouts, column, row, grid and frame, plus divider. Modifiers set the gap, alignment, padding,
size and scrolling, and common patterns come from combining the two.
